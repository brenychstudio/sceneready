# Contributing to SceneReady

SceneReady welcomes focused, reviewable contributions to its public open-source codebase.

## Development requirements

- Use Node.js 22.x.
- Use npm only. Do not introduce another JavaScript package manager or lockfile.
- Prefer a test-before-implementation workflow: write a focused failing test, observe the expected failure, implement the smallest change, and run the tests again.
- Never commit secrets, credentials, customer data, client data, or real production personal data.
- All contributions must be clean-room work. Do not copy private BDB source or any code, documentation, assets, configuration, prompts, schemas, or implementation files from private or pre-existing Brenych projects.
- Keep commits small, cohesive, and reviewable.

## Before submitting a change

Run the relevant tests and repository validation commands, review the complete diff, and document any known limitations. Contributions must comply with the license, security policy, code of conduct, and applicable rights records.
