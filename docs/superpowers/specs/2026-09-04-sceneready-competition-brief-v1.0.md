# SceneReady Competition Brief v1.0

## One-sentence product

SceneReady is a hands-free production-readiness system that turns crew, location, light, weather, travel, equipment and rights into deterministic readiness, causal risk intelligence and human-approved recovery actions.

## Canonical demo

Synthetic AER / SS27 Barcelona fashion campaign: Gothic Quarter -> Eixample -> Studio. Eight-person crew. Seven typed deliverables. Compound contingency: exterior weather window -35 min + travel/load-in +14 min.

## Why it can win

Not a Q&A bot or basic MCP wrapper: typed causal graph, creative-intent envelopes, deterministic readiness, shadow simulation, bounded Bedrock recovery, explicit human authority, real AWS execution and judge-visible resilience proofs.

## AWS stack

AgentCore Runtime, Bedrock + Strands, DynamoDB, EventBridge + Lambda, Amazon Location Routes V2, SQS + Lambda/DLQ, S3, Cognito, CloudWatch/OTEL, AWS CDK.

## Competition strategy

Alexa+ Primary + AWS Builder + Open Source. Maintain friction logs for possible bonus. Real MCP server mandatory; actual Alexa+ add-on preferred, simulated Alexa+ experience retained as rules-permitted fallback if access is unavailable.
