# Asset Rights Register

## Bootstrap state

- Distributed media assets at bootstrap: NONE
- Third-party visual assets at bootstrap: NONE
- Third-party audio assets at bootstrap: NONE
- Fonts bundled in repository at bootstrap: NONE

## Future asset records

Each future distributed asset must be recorded with all of the following fields before it is added:

- Asset ID
- Path
- Source/creator
- License/rights basis
- Repository redistribution allowed
- Competition video use allowed
- Attribution requirement
- Evidence/reference
